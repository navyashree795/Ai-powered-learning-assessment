# 🌟 Special Needs Learning Companion (Online Learning Platform)

An AI-powered, accessible learning companion designed to empower students with diverse learning needs (including **Dyslexia**, **ADHD**, and **Autism Spectrum**). The platform provides tailored learning experiences, AI-driven adaptive recommendations, speech assistance, multisensory tools, and dedicated portals for parents and educators.

---

## 📱 Project Overview

The repository consists of two integrated applications:

1. **`special-needs-companion` (Web Application)**
   - Built with **React 19**, **Vite**, and **React Router**.
   - Features dynamic neurodiversity self-assessments, personalized learning strategies generated by **Google Gemini AI**, high-accessibility UI themes (Dyslexia-friendly fonts, high-contrast mode, calming sensory palettes), real-time Firebase integration, a **Teacher Dashboard**, and a **Parent Digest**.

2. **`mobile-companion` (Cross-Platform Mobile Application)**
   - Built with **React Native**, **Expo (SDK 54)**, and **Expo Router**.
   - Provides on-the-go accessibility with **Expo Speech** (Text-to-Speech / audio assistance), **Expo Haptics** feedback, interactive assessment modules, Gemini AI assistant, and synchronized parent/teacher insights.

---

## ✨ Key Features

- 🧠 **AI-Powered Adaptive Assessment**: Identifies student strengths and challenges across reading, sensory processing, and focus to generate personalized learning paths via Google Gemini.
- 📖 **Dyslexia Support Tools**: Reading aids, adjustable typography (OpenDyslexic friendly styling), text spacing, and real-time Text-to-Speech read-aloud.
- ⚡ **ADHD Focus & Micro-Learning**: Structured bite-sized tasks, minimal distraction modes, visual timers, and engaging sensory checkpoints.
- 🌈 **Autism & Sensory Accommodations**: Predictable routine trackers, calming color schemes, reduced sensory stimulation modes, and clear visual cues.
- 👨‍🏫 **Teacher Dashboard**: Track student learning progress, view assessment summaries, and adapt classroom support strategies.
- 👪 **Parent Digest**: Actionable daily/weekly learning insights, emotional check-ins, and home study recommendations.
- 🔄 **Cloud Synchronization**: Backed by Firebase for cross-device state management and progress tracking.

## 🛠️ Tech Stack

### Web Application (`special-needs-companion`)
- **Framework**: React 19, Vite
- **Routing**: React Router DOM v7
- **AI Integration**: Google Generative AI SDK (`@google/generative-ai` / Gemini Flash)
- **Backend & Database**: Firebase (Auth, Firestore / Realtime Database)
- **Styling**: Vanilla CSS with accessible design systems and CSS custom properties

### Mobile Application (`mobile-companion`)
- **Framework**: React Native 0.81, Expo SDK 54
- **Navigation**: Expo Router v6 (File-based navigation)
- **Hardware & Multimedia**: `expo-speech` (TTS), `expo-haptics`, `expo-font`, `expo-image`
- **AI Integration**: Google Generative AI SDK (`@google/generative-ai`)
- **Backend**: Firebase SDK v10

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18.x or 20.x recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [Expo Go](https://expo.dev/go) app on your mobile device (for running the mobile app), or an Android/iOS emulator
- A [Google Gemini API Key](https://aistudio.google.com/)
- A [Firebase Project](https://console.firebase.google.com/)

---

### 1. Web Application Setup (`special-needs-companion`)

1. Navigate to the web app directory:
   ```bash
   cd special-needs-companion
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file in `special-needs-companion/` with your API keys:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open [http://localhost:5173](http://localhost:5173) in your browser.

---

### 2. Mobile Application Setup (`mobile-companion`)

1. Navigate to the mobile app directory:
   ```bash
   cd mobile-companion
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Configure your API keys in `ai.js` or environment variables as required.

4. Start the Expo development server:
   ```bash
   npm start
   ```

5. Open the project:
   - Scan the QR code using the **Expo Go** app on Android or the Camera app on iOS.
   - Or press `a` to launch Android Emulator / `i` for iOS Simulator / `w` for Web.

## 💡 Usage Workflow

1. **Student Onboarding & Self-Assessment**: The student takes an interactive, stress-free questionnaire evaluating sensory, focus, and reading preferences.
2. **Personalized Strategy Generation**: Gemini AI analyzes responses to suggest targeted learning strategies (e.g., visual breakdowns, audio-assisted reading, focus sprints).
3. **Multisensory Study Session**: The student interacts with reading materials using built-in Text-to-Speech and high-legibility accommodations.
4. **Collaborative Insights**: Parents review study summaries via **Parent Digest**, while teachers monitor class-wide progress and individual accommodations via **Teacher Dashboard**.
